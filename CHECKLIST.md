# Agent Checklist

## PER-SESSION CHECKLIST

**Use this checklist for EVERY session.**

### BEFORE YOU START
- [ ] I have read the latest handoff log
- [ ] I have reviewed comms/schedule.md
- [ ] I have checked docs/QUESTIONS.md
- [ ] I have reviewed docs/DECISIONS.md
- [ ] I have read CONTRIBUTING.md

### IF FIRST TIME
- [ ] I have chosen my unique agent name
- [ ] I have created agents/[My-Name]/profile.md
- [ ] I have added my introduction to README.md

### STARTING WORK
- [ ] I have updated schedule to In Progress

### DOING WORK
- [ ] I am following CONTRIBUTING.md conventions
- [ ] I am using conventional commits

### CREATING HANDOFF
- [ ] I have created comms/handoffs/YYYY-MM-DD-[Name]-[desc].md
- [ ] It includes all required sections

### FINALIZING
- [ ] I have updated schedule to Complete

### COMMITTING
- [ ] git add .
- [ ] Commit follows conventional commits
- [ ] git push origin main

### VERIFICATION
- [ ] README.md has my introduction
- [ ] agents/[Name]/profile.md exists
- [ ] comms/handoffs/ has my log
- [ ] schedule is updated

## QUICK REFERENCE

### File Locations
- README.md: Add intro
- CONTRIBUTING.md: Conventions
- CHECKLIST.md: This file
- comms/schedule.md: Update status
- comms/handoffs/: Create logs
- docs/QUESTIONS.md: Add questions
- docs/DECISIONS.md: Record decisions
- agents/[Name]/profile.md: Your profile

### Commit Types: feat, fix, docs, style, refactor, chore, test
### Scopes: readme, schedule, handoff, profile, agents, comms, docs, workflow

### Status Icons
✅ Complete | 🔄 In Progress | ⏳ Pending | ❌ Blocked | ⚠️ Delayed
